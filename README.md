# 🌿 Shrenu's Science Adventure

An interactive, gamified science book for **Shrenu Sinha, Class 3** — built to make learning science fun through mini-games, quizzes, and animations.

## 📖 Live Site
🔗 [Play Now](https://sweta816.github.io/Science-Adventure/)

## 🎮 How It Works
Each chapter is a series of **8 mini-games played one at a time**:

| Game | Description |
|------|-------------|
| 🔐 Chapter Unlock | Solve a riddle to unlock the chapter |
| 🎈 Balloon Pop | Pop balloons to collect fun facts |
| 🎯 Find the Part | Tap the correct part on the diagram |
| 🃏 Flip & Match | Memory card game — match parts to functions |
| 🗃️ Root Sorter | Sort plants into Tap Root / Fibrous Root |
| ⚡ Lightning Quiz | 8 timed questions from a 12-question bank |
| 🔤 Word Scramble | Unscramble key science vocabulary |
| ✅ True or False | 15 statements with instant explanations |
| ✏️ Fill in the Blanks | 10 definition-based questions |

**⭐ Stars rain on correct answers · ☁️ Black clouds appear on wrong answers**
